# Анализ фазовых сдвигов генератора Колпитца при внешней помехе

Кодовая база для научной статьи: исследование зависимости фазового сдвига колебаний генератора Колпитца от фазы попадания внешней импульсной помехи.

## Источники данных

Проект обрабатывает два типа данных:

1. **Экспериментальные** (`csv_files/`) — 101 CSV-файл с осциллографа.
   Файл `0.csv` — эталон без помехи, файлы `1.csv`–`100.csv` — помеха подаётся в случайную фазу.
   Параметры: 16384 отсчёта, dt = 50 нс, f ~ 158 кГц.

2. **LTSpice-моделирование** (`LTSpice/`) — схемы на BJT (2N3904) и MOSFET (IRF640).
   Параметрический sweep (`.step param Tdelay`) сканирует фазу помехи от 0 до 2pi.
   Адаптивная сетка: dt от 10 нс до 615 нс, f ~ 71 кГц.

## Ключевые формулы

**Период:** `period[i] = crossing[i+2] - crossing[i]`
(через два пересечения, т.к. каждое второе = полный период)

**Классификация:**
- «До помехи»: `crossing[i+2] < t_perturbation` (весь период завершился до помехи)
- «После помехи»: `crossing[i] >= t_perturbation` (весь период начался после помехи)

**Фазовый сдвиг:**
```
T_avg = mean(periods_before)
delta_phase = (sum(all_periods) - T_avg * N_total) / T_avg
```

**Фаза помехи (0–2pi):**
Интерполяция между пересечениями нуля, окружающими момент помехи:
- Восходящее пересечение (фаза 0): `phase = frac * pi`
- Нисходящее пересечение (фаза pi): `phase = pi + frac * pi`

## Критически важное отличие LTSpice от эксперимента

LTSpice использует **адаптивный** шаг (Gear/trapezoidal), шаг сетки варьируется от 10 нс до 615 нс (60x разброс). Экспериментальные данные имеют фиксированный dt = 50 нс.

Поэтому в `pipeline_ltspice.py` все вычисления идут **в секундах**, а не в индексах. Дробные индексы пересечений нуля конвертируются в моменты времени через линейную интерполяцию:

```python
t(c) = time[floor(c)] + frac(c) * (time[floor(c)+1] - time[floor(c)])
```

Без этой конвертации фазовые сдвиги получались +/-700 градусов вместо реальных +/-40 градусов.
